# Changelog

All notable changes to Herald are documented here. A release is what the in-app
update check compares against, so releases are cut deliberately.

## 1.0.0

First public release - a multihub **ADC** release announcer for DC++ / luadch-ng
hubs. Watches folders for finished releases and announces them to one or more
hubs. One config, two front-ends: a Qt GUI (dark + light) and a headless CLI /
Docker runner sharing a single Qt-free engine.
